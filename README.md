# Traffic Mod

Add realistic traffic features to your Minecraft world

## Features

- Adds realistic roads to your Minecraft world
- Includes traffic signs and lights for better navigation
- Features police stations, hospitals, and gas stations
- Allows for editable signs to customize your traffic elements

## Requirements

- Minecraft 1.19.2 or 1.20
- Forge 43 or later

## Installation

1. Download the mod from the releases page
2. Place the mod file in your Minecraft mods folder
3. Launch Minecraft with Forge

## Usage

Once installed, you can place the traffic blocks in your world using the creative inventory. The blocks include:

- Road
- Traffic Sign
- Traffic Light
- Police Station
- Hospital
- Gas Station
- Editable Sign

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
